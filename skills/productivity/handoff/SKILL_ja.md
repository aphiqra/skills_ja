name: handoff
description: 現在の会話を、別のエージェントが引き継げるハンドオフ文書へ圧縮する。
argument-hint: "次のセッションは何のために使いますか？"
disable-model-invocation: true
---

現在の会話を要約したハンドオフ文書を作成し、新しいエージェントが作業を継続できるようにしてください。保存先は現在のワークスペースではなく、ユーザーの OS の一時ディレクトリです。

文書には「推奨スキル」セクションを含め、次のエージェントが呼び出すべきスキルを提案してください。

他の成果物（仕様書、計画書、ADR、issue、コミット、差分など）にすでに記録されている内容を重複記載しないでください。代わりにパスまたは URL を参照してください。

API キー、パスワード、個人を特定できる情報などの機密情報はマスキングしてください。

ユーザーが引数を渡した場合、それを次回セッションの焦点に関する説明として扱い、それに合わせて文書を調整してください。
