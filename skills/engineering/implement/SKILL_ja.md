---

ユーザーが指定した仕様またはチケットに基づいて作業を実装します。

ユーザーがチケットの参照を渡した場合は、作業を始める前に issue tracker からそのチケットを取得し、タイトルを伝えてください。参照が曖昧な場合は確認してください。

可能な限り、事前に合意された境界で Skill tool を "tdd" で呼び出してください。

型チェックを定期的に実行し、単一のテストファイルも定期的に実行し、最後にテストスイート全体を実行します。

完了後、Skill tool を "code-review" で呼び出して作業をレビューします。

作業内容を現在のブランチにコミットしてください。
