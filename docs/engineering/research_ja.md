```bash
npx skills add mattpocock/skills --skill=research
```

```bash
npx skills update research
```

[Source](https://github.com/mattpocock/skills/tree/main/skills/engineering/research)

## 機能

`research` は、答えを持つ情報源を読み込み、その内容を引用付きの Markdown ファイルとして残すことで質問に答えます。利用するのは **一次情報源** のみです。公式ドキュメント、ソースコード、仕様書、ファーストパーティ API などを対象とし、それらを解説した二次情報は利用しません。そのため、保存される内容は「要約の要約」ではなく、権威ある情報源まで追跡可能です。

## この機能を使うタイミング

`/research` と入力するか、タスクが情報収集作業へ変わった場合はエージェントが自動的に利用します。

次に必要なのが *何かを調べること* の場合に利用してください。たとえば、API がどのように動作するのか、仕様書には実際に何と書かれているのか、ある主張が正しいのか、といったことを確認したい場合です。自分で読み込む作業に時間を使いたくないときに役立ちます。読解ではなく対話によって計画を磨きたい場合は [grilling](https://aihero.dev/skills-grilling) を利用してください。また、使い捨てコードによって何を作るべきかを探りたい場合は [prototype](https://aihero.dev/skills-prototype) を利用してください。

## 委任された下調べ

このスキルの特徴は、読解作業が **バックグラウンドエージェント** として実行される点です。あなたは他の作業を続けながら、スキルは各主張を一次情報源までたどり、引用付きの Markdown ファイルを 1 つ作成して、リポジトリ内でその種のメモを保存する場所へ配置します。調査とは、思考を外注することではなく、下調べを委任することです。返されるのは、出典付きで検討できる文書です。

## この機能の位置付け

必要なときにいつでも利用できる**スタンドアロン型スキル**であり、思考系スキルの入力を提供します。生成されるファイルは、さらに議論したり、計画を立てたり、設計したりするための材料となります。そのため、開発チェーンの一工程ではなく、[grilling](https://aihero.dev/skills-grilling) や [to-prd](https://aihero.dev/skills-to-prd) のような作業の上流に位置します。全体像については [ask-matt](https://aihero.dev/skills-ask-matt) を参照してください。
